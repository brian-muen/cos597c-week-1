Method, scoring & limitations +

This is a synthetic pilot, not a general math benchmark. The 60 questions shown here contain 20 straightforward arithmetic questions, 20 large-integer calculations, and 20 verdict-only verification claims (10 true, 10 false).

Both conditions use Nemotron-3-Nano-30B-A3B at temperature 0 with reasoning disabled and 4,096 output tokens per call. The calculator condition also explicitly instructs tool use and allows up to four model calls, so the comparison measures access plus that instruction.

Final-answer scoring accepts formatting differences and explanations. Calculation tasks require an exact numerical answer; verification requires only the correct verdict. The scorer was corrected after collection began; original responses were preserved. Four base responses reached the output limit; there were no API errors.

The accuracy-gain interval uses 10,000 stratified paired-bootstrap samples. A single generation per question and shared templates limit generalization: 60/60 here does not imply perfect accuracy on new questions. The calculator accuracy’s 95% Wilson interval is 94.0–100%.
